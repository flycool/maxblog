> 模块 1 / 7 | 预估 6-8 周

## 第一阶段：图论基础 (1-1.5 周)

### 1.1 图的表示
- **邻接矩阵** `O(V²)` 空间 — 适合稠密图
- **邻接表** `O(V+E)` 空间 — 最常用
- **边列表** — 适合按边操作的场景 (如 Kruskal)
- 带权图、有向/无向图如何存储

**动手**：手写三种表示的转换函数

### 1.2 图的分类
- 有向图 vs 无向图
- 带权图 vs 无权图
- 连通图、完全图、稀疏/稠密图
- 树 (Tree) = 无环连通图，`E = V-1`
- 有向无环图 (DAG)、二分图
- 度、入度、出度、路径、环

### 1.3 基础遍历

#### BFS (广度优先)
- 队列实现，按层遍历
- 应用：最短路径 (无权图)、层级遍历、连通分量
- 复杂度：`O(V+E)`

#### DFS (深度优先)
- 递归 / 栈实现
- 应用：检测环、拓扑排序、连通分量、回溯
- 复杂度：`O(V+E)`

**经典题**：
- [ ] LeetCode 200 岛屿数量 (DFS/BFS 模板题)
- [ ] LeetCode 695 岛屿最大面积
- [ ] LeetCode 994 腐烂的橘子 (BFS 层数)
- [ ] LeetCode 133 克隆图
- [ ] LeetCode 547 省份数量 (连通分量)

## 第二阶段：核心算法 (2 周)

### 2.1 最短路径

| 算法             | 适用                 | 时间复杂度            |
| -------------- | ------------------ | ---------------- |
| BFS            | 无权图                | `O(V+E)`         |
| Dijkstra       | 非负权图               | `O((V+E) log V)` |
| Bellman-Ford   | 可负权，检测负环           | `O(VE)`          |
| SPFA           | Bellman-Ford 的队列优化 | 平均快，最坏 `O(VE)`   |
| Floyd-Warshall | 全源最短路              | `O(V³)`          |
| A*             | 带启发式的路径搜索          | 取决于启发函数          |

**Dijkstra 核心直觉**：每次选当前距离最小的未确定点，松弛它的所有邻居。用优先队列维护。

**Bellman-Ford 核心直觉**：对所有边进行 V-1 轮松弛，每轮至少确定一个点的最短距离。第 V 轮还能松弛说明有负环。

**Floyd-Warshall 核心直觉**：`dp[k][i][j]` = 只用前 k 个点作为中间点，i 到 j 的最短路。空间可优化到二维。

**经典题**：
- [ ] LeetCode 743 网络延迟时间 (Dijkstra 模板)
- [ ] LeetCode 787 K 站中转最便宜航班 (Bellman-Ford / BFS)
- [ ] LeetCode 1514 概率最大的路径 (Dijkstra 变体)
- [ ] LeetCode 1631 最小体力消耗路径 (Dijkstra / 二分+并查集)
- [ ] LeetCode 1334 阈值距离内邻居最少城市 (Floyd-Warshall)

### 2.2 最小生成树 (MST)

| 算法      | 思路                     | 时间复杂度            |
| ------- | ---------------------- | ---------------- |
| Prim    | 类似 Dijkstra，从点出发选最小边扩展 | `O((V+E) log V)` |
| Kruskal | 按边权排序，用并查集判断连通性        | `O(E log E)`     |

**Prim 直觉**：从一个点开始，每次挑一条连接「已在树中」和「不在树中」的最小权边。

**Kruskal 直觉**：全局按边权从小到大考虑，如果边的两端不在同一集合就加入，否则跳过。

**经典题**：
- [ ] LeetCode 1584 连接所有点的最小费用 (Prim/Kruskal 模板)
- [ ] LeetCode 1135 最低成本联通所有城市 (MST 基础题)
- [ ] LeetCode 1168 水资源分配优化 (虚拟节点技巧)

### 2.3 拓扑排序

- 只适用于 DAG
- Kahn 算法 (BFS + 入度表)：`O(V+E)`
- DFS 后序遍历法：`O(V+E)`
- 应用：任务调度、依赖解析、课程安排

**经典题**：
- [ ] LeetCode 207 课程表 (检测环 / 拓扑排序可行性)
- [ ] LeetCode 210 课程表 II (输出拓扑序)
- [ ] LeetCode 310 最小高度树 (拓扑排序剥洋葱)
- [ ] LeetCode 329 矩阵中的最长递增路径 (DAG 上的最长路)
- [ ] LeetCode 802 找到最终安全状态 (反向图拓扑排序)

## 第三阶段：进阶图论 (2 周)

### 3.1 并查集 (Union-Find / DSU)

- 路径压缩 + 按秩合并
- 近乎 `O(1)` 均摊操作
- 应用：连通性判断、Kruskal、动态连通性

**经典题**：
- [ ] LeetCode 684 冗余连接 (并查集找环)
- [ ] LeetCode 1319 连通网络的操作次数
- [ ] LeetCode 399 除法求值 (带权并查集)
- [ ] LeetCode 1202 交换字符串中的元素

### 3.2 强连通分量 (SCC)

- Kosaraju 算法：两次 DFS，第二次在反图上
- Tarjan 算法：一次 DFS，用 low-link 值
- 缩点后得 DAG (缩点图 / condensation graph)

**经典题**：
- [ ] LeetCode 1568 使陆地分离的最少天数 (割点/桥思维)

### 3.3 二分图

- 染色法判断二分图 (BFS/DFS)
- 最大匹配：匈牙利算法 `O(VE)`
- 最小顶点覆盖、最大独立集 (Konig 定理)

**经典题**：
- [ ] LeetCode 785 判断二分图
- [ ] LeetCode 886 可能的二分法

### 3.4 网络流入门

- Ford-Fulkerson：DFS 找增广路
- Edmonds-Karp：BFS 找最短增广路 `O(VE²)`
- Dinic：分层图 + 阻塞流 `O(V²E)`，实践中很快
- 最大流 = 最小割

**经典题**：
- [ ] LeetCode 2172 最大化和相等的数组和 (状压 DP，备选)
- [ ] 洛谷 P3376 网络最大流 (Dinic 模板)

### 3.5 欧拉路径 & 哈密顿路径

- 欧拉路径：每条边恰好走一次 (Fleury/Hierholzer 算法)
- 哈密顿路径：每个点恰好走一次 (NP 完全，一般用状压或回溯)

**经典题**：
- [ ] LeetCode 332 重新安排行程 (欧拉路径 / Hierholzer)
- [ ] LeetCode 980 不同路径 III (哈密顿路径 / 状压 DP)

## 第四阶段：综合练习 & 技巧总结 (1.5-2 周)

### 4.1 常见图论模式

| 模式          | 关键点                          |
| ----------- | ---------------------------- |
| **建图**      | 隐式图构建 (状态→节点)，虚拟节点技巧         |
| **多源 BFS**  | 多个起点同时入队，等价于超级源点             |
| **反向图**     | 求「能到达终点的点」→ 从终点反向遍历          |
| **二分 + 图论** | 二分答案后用 BFS/并查集/最短路判定         |
| **缩点**      | SCC 缩点成 DAG 后在 DAG 上 DP/拓扑排序 |
| **拆点**      | 每个节点拆成多个状态节点 (如带状态的最短路)      |
| **虚拟节点**    | 减少边数 (如 MST 中虚拟水源节点)         |

### 4.2 综合练习

- [ ] LeetCode 1192 查找集群内的关键连接 (Tarjan 求桥)

- [ ] 不看模板写出：BFS、DFS、Dijkstra、Kruskal、拓扑排序、并查集
