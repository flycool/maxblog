# 算法学习路线图

> **目标**：系统、深入地理解算法与数据结构，夯实内功
> **节奏**：按模块灵活推进，重理解胜过重题量

---

## 学习原则

1. **先理解，后刷题** — 每个算法先搞懂「解决了什么问题」和「核心直觉」，再做题
2. **手写实现** — 核心算法至少手写 2-3 遍，不看模板写出来才算会
3. **复杂度分析** — 每个算法都要能分析时间/空间复杂度，这是内功
4. **总结 > 题量** — 做完题写一句话总结：这题的关键 trick 是什么
5. **定期回顾** — 每周日回顾本周学的，每月底回顾本月的

## 模块总览

| 模块             | 内容                         | 预估周期  |
| -------------- | -------------------------- | ----- |
| **1. 图论**      | 遍历、最短路、生成树、拓扑排序、网络流        | 6-8 周 |
| **2. 动态规划**    | 线性 DP、背包、区间 DP、树形 DP、状压 DP | 6-8 周 |
| **3. 贪心 & 分治** | 贪心策略、分治框架、二分答案             | 3-4 周 |
| **4. 高级数据结构**  | 并查集、树状数组、线段树、平衡树、Trie      | 4-5 周 |
| **5. 字符串**     | KMP、Trie、AC 自动机、后缀数组入门     | 3-4 周 |
| **6. 数学 & 数论** | 素数、快速幂、GCD、组合数学、概率         | 3-4 周 |
| **7. 综合练习**    | 综合题、难题拆解、比赛模拟              | 4 周   |

## 推荐资源

- **书籍**：《算法导论》(CLRS) — 当字典查；《算法》第四版 (Sedgewick) — 适合跟学

- **复杂度速查**：[Big-O Cheat Sheet](https://www.bigocheatsheet.com/)
